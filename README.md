This code supports the manuscript:
Isaacs, KK, Wambaugh JF, Charest N, Sinclair G, Shapiro AJ, Whitehead H, Boatman A, Ferland TM, Wall JT,
Wilson M, Sams RL, Edwards S, Thomas RS, and Paul Friedman K. Characterizing Exposure Pathways for a Global
Collection of Chemicals. 2026. Submitted to Environmental Sciences and Technology.

Reproducible code is available in ROCKS_Exposure_analyses.rmd. Output PNGs
and CSV files can be regenerated with the code into a folder "Output", using input datasets
provided in expected "Data" folder format at link below. Rendered analysis and figure results (with accompanying code)
are also provided in ROCKS_Exposure_analyses.html. 

Input datasets for this code are available here:

Isaacs, Kristin (2026). Data and Code Supporting Manuscript "Characterizing Exposure Pathways for a Global Collection of Chemicals". UL Research Institutes. Dataset. https://doi.org/10.60752/102376.34455093
